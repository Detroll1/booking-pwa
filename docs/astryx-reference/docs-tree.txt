Usage: npx @astryxdesign/cli docs <topic>                  list a topic's sections
       npx @astryxdesign/cli docs <topic> <section>        read one section
       npx @astryxdesign/cli docs <topic> --full           read the whole topic
       npx @astryxdesign/cli docs cli/api                  go down the docs tree one level at a time
With --json, a topic returns its whole doc; add --index for its section list.
